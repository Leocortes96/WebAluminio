# Tarea 4 · Propuestas SEO y comerciales por portafolio

Fuente: `data/portafolio_seo_propuesto.csv` (títulos ≤ 60 y metas de 120 a 155 caracteres, ya validados).

## Cómo aplicarlo

- **Título SEO y meta descripción:** instalar **Rank Math SEO (gratis)** y pegarlos en el panel de Rank Math de cada portafolio. Por API solo es posible con el endpoint interno `rankmath/v1/updateMeta` o con el plugin auxiliar *Rank Math API Manager*. Se haría después de un respaldo y un dry-run, igual que con los alt.
- **Beneficios y CTA:** viven en Elementor (`_elementor_data`), que **no se puede editar de forma segura por la API REST** (el tipo `portafolio` no expone ese metadato y `elementor/v1/documents` es solo de lectura). Alternativa recomendada: pegar el texto en el editor de Elementor (widget de texto + botón). Otras opciones, con más riesgo: exponer `_elementor_data` con un snippet temporal o usar el MCP de Elementor que ya está instalado.
- El botón de WhatsApp lleva un mensaje prellenado con la URL de origen, para saber qué producto generó el contacto.
